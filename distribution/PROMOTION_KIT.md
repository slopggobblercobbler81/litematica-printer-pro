### A. For `r/feedthebeast` (Modded Minecraft Showcase)
**Title:**
> [Showcase] LiteBuilder (Litematica Printer Pro) — Fast schematic auto-placement with smart redstone delay cycling & note block pitch tuning (1.20.1 - 26.3)

**Body:**
```markdown
Hey everyone! 👋

If you use Litematica to plan complex builds or massive redstone contraptions, you know how painful it can be when auto-printers place repeaters with the wrong delay, observers backwards, or fail to tune note blocks.

I've put together **LiteBuilder**, a modern, lightweight Fabric companion mod for Litematica built for smooth, accurate auto-placement:

### 🌟 Key Features:
- 🔄 **Smart Directional Rotation**: Calculates exact view angles for repeaters, comparators, observers, pistons, dispensers, droppers, crafters, and stairs.
- 🎵 **Note Block Pitch Tuning**: Detects placed note blocks and automatically cycles right-clicks to match schematic pitch (0–24 notes) — perfect for music engines!
- ⏱️ **Redstone State Adjustment**: Automatically tunes repeater delays (1–4 ticks), comparator modes (Compare vs Subtract), and daylight detectors in-place.
- 🛡️ **Anti-Thrashing Inventory Batching**: Groups placements by item ID and synchronizes hotbar slots via network packets, eliminating ghost blocks and accidental item swapping under high placement speeds.
- 🌐 **Carpet Protocol & Vanilla Fallback**: Supports Carpet Accurate Placement protocol v2/v3 when present, with automatic surface hit fallback for vanilla/fabric servers (no coordinate rejection!).
- ⚡ **Configurable Speed & Reach**: Reach up to 64 blocks, speeds from 1 to 20 blocks/tick.

Supports Minecraft **1.20.1 through 26.3** on Fabric & Quilt!

🔗 **Links**:
- [Modrinth](https://modrinth.com/mod/litebuilder)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/litebuilder)
- [GitHub](https://github.com/slopggobblercobbler81/litematica-printer-pro)

Feedback and suggestions are very welcome!
```

**Body:**
```markdown
Hi TMC community!

Most Litematica schematic builders either place repeaters on 1-tick delay default or place observers facing the player's camera instead of the schematic orientation.

We built **LiteBuilder** to address this for technical players:
1. **In-place State Cycling**: Automatically right-clicks repeaters to match the schematic delay (1 to 4 ticks) and toggles comparator subtract mode.
2. **Note Block Tuning**: Cycles note block pitch (0–24) to match the blueprint.
3. **Vanilla & Carpet Compatible**: Spoofs player yaw/pitch cleanly on vanilla/fabric servers, and utilizes Carpet Accurate Placement protocol if available.
4. **Dependency-First Ordering**: Places solid supporting blocks first so redstone dust, repeaters, and torches never pop off.
```
