⚡ LiteBuilder (Litematica Printer Pro)

LiteBuilder is a high-performance, client-side Fabric mod that adds intelligent automatic block placement for schematics loaded through Litematica. It places blocks matching the schematic outline as you move around, with support for directional block rotation, redstone state adjustment, note block pitch tuning, configurable reach, and inventory restocking.

🌟 Key Features

  • Intelligent Auto-Placement: Support-aware bottom-to-top placement that respects foundation dependencies before placing fragile blocks (torches, redstone wire, repeaters, rails, ladders).
  • Directional Smart Rotation: Correctly places repeaters, comparators, observers, pistons, sticky pistons, dispensers, droppers, crafters, stairs, slabs, and chests using precise player orientation spoofing.
  • 🎵 Note Block Pitch Tuning: Automatically right-clicks placed note blocks to match schematic pitch (0 to 24 notes). Perfect for noteblock song machines and redstone music engines!
  • ⏱️ Redstone State Adjustment: Automatically cycles repeater delays (1–4 ticks), toggles comparator modes (Compare vs Subtract), and adjusts daylight detectors, levers, and doors/gates in-place.
  • 🛡️ Anti-Thrashing Inventory Batching: Groups placements by item ID and synchronizes hotbar slots via network packets before placing, preventing ghost blocks and accidental item swapping.
  • 🌐 Carpet Protocol & Vanilla Fallback: Full support for Carpet Accurate Placement protocol v2 and v3, with safe coordinate fallback for vanilla servers.
  • Configurable Reach & Speed: Placement reach up to 64.0 blocks and speeds from 1 to 20 blocks per tick.
  • 🧹 Break Wrong Blocks (Optional): Automatically removes incorrectly placed or obstructing blocks to re-place them with correct orientation.
  • In-Game Configuration: Configurable through MaLiLib's in-game config menu (M + C) or Mod Menu.

🎮 Controls

  • V: Toggle automatic placement on or off.
  • B: Cycle placement speed (1, 3, 5, or 10 blocks per tick).
  • M + C: Open the MaLiLib in-game configuration menu.

Keybindings can be remapped in Options > Controls > Key Binds under the LiteBuilder category.

⚙️ Settings

Settings can be changed in the in-game menu (M + C) or in .minecraft/config/litebuilder.json:

  • printerEnabled (default: false): Master toggle for automatic placement.
  • placementRange (default: 4.5, range: 1.0 - 64.0): Reach distance in blocks from the player.
  • blocksPerTick (default: 3, range: 1 - 20): Maximum blocks placed per client tick.
  • placementIntervalTicks (default: 1): Delay in ticks between placement cycles.
  • smartRotationEnabled (default: true): Resolves face hit angles for directional blocks.
  • carpetAccuratePlacement (default: true): Sends Carpet-compatible placement protocol packets when supported.
  • tuneNoteBlocks (default: true): Automatically tunes note blocks to match schematic pitch.
  • inventoryBufferCache (default: true): Caches inventory slots to minimize lookup overhead during fast placement.
  • breakWrongBlocks (default: false): Breaks incorrectly placed blocks obstructing the schematic.
  • strictRaycast (default: false): Enforces line-of-sight checks before placing blocks.
  • showHud (default: false): Optional on-screen placement HUD.

📦 Dependencies

  • Fabric Loader (>= 0.16.0)
  • Fabric API
  • MaLiLib
  • Litematica

🧩 Supported Versions

Minecraft 1.20.1, 1.20.2, 1.20.4, 1.20.6, 1.21, 1.21.1, 1.21.2, 1.21.3, 1.21.4, and 26.3 on Fabric and Quilt.
