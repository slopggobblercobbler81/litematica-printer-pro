⚡ Litematica Printer Pro

Litematica Printer Pro is a high-performance, intelligent auto-placement Fabric companion mod for Masa's Litematica. Built natively for modern Minecraft (with full Minecraft 26.3 and 1.21.4 support), it delivers rapid, dependable schematic printing without annoying screen clutter or manual orientation headaches.

🌟 Key Features

  • ⚡ Smart Auto-Placement Engine: High-throughput placement bursts configurable from 1 to 20 blocks per tick.
  • 🏗️ Topological Dependency Resolution: Automatically places support blocks before attaching torches, redstone dust, repeaters, comparators, rails, and ladders.
  • 🔄 Carpet & Masa Accurate Placement Protocol (v2 & v3): Flawless orientation for directional blocks (stairs, slabs, observers, pistons, hoppers) without camera snapping.
  • 🔭 Extended 64-Block Reach: Fully configurable reach distance from 1.0 up to 64.0 blocks with spherical distance candidate early pruning.
  • 🎒 Inventory Buffer Caching: Instant hotbar swapping directly from main inventory and shulker box container inspection.
  • 💬 Clean Actionbar Feedback: Zero screen clutter! Status and speed adjustments are cleanly presented via vanilla actionbar notifications above the hotbar.
  • ⚙️ MaLiLib & Mod Menu Integration: Configure options in-game directly via M + C or Mod Menu.

⌨️ Controls & Keybindings

Keybinding Default Key Action
Toggle Printer V Toggles automatic schematic block placement on or off.
Cycle Placement Speed B Cycles burst throughput through 1 ➔ 3 ➔ 5 ➔ 10 blocks/tick.
Open MaLiLib Config M + C Opens the MaLiLib in-game configuration menu.

📦 Requirements & Installation

  1. Install Fabric Loader (>=0.16.0, tested with 0.19.5+) for Minecraft 26.3 or 1.21.4.
  2. Install Fabric API, MaLiLib, and Litematica.
  3. Place litematica-printer-pro-26.3-1.0.0.jar into your .minecraft/mods folder.
  4. Launch Minecraft, load your schematic in Litematica, and press V to build!
