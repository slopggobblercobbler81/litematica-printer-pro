# LiteBuilder v1.0.0

LiteBuilder is a client-side Fabric mod that adds automatic block placement for schematics loaded through Litematica. It places blocks matching the schematic outline as you move around, with support for directional block rotation protocols, configurable reach, and inventory restocking.

## Changes in v1.0.0

- Added automatic block placement engine with support-block dependency ordering.
- Implemented Carpet and Masa accurate block placement protocol support (v2 and v3) for accurate directional block placement.
- Added reach distance configuration up to 64.0 blocks.
- Added inventory restocking cache for hotbar management.
- Unobtrusive actionbar status notifications when toggling placement or changing speed.
- In-game configuration through MaLiLib (M + C) and Mod Menu.
- Compatible with Minecraft 1.20.1 through 26.3 on Fabric Loader 0.16.0+.

## Keybindings

- V: Toggle placement on or off.
- B: Cycle placement speed (1, 3, 5, 10 blocks/tick).
- M + C: Open MaLiLib configuration menu.
