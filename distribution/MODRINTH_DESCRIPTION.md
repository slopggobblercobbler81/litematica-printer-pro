# ⚡ Litematica Printer Pro

**Litematica Printer Pro** is a high-performance, intelligent auto-placement Fabric companion mod for Masa's [Litematica](https://modrinth.com/mod/litematica). Built natively for modern Minecraft (Minecraft 26.3 & 1.21.4), it enables rapid, dependable schematic printing without annoying screen clutter or manual orientation headaches.

---

## 🌟 Key Features

- ⚡ **High-Throughput Placement**: Burst speeds up to 20 blocks/tick with intelligent topological support resolution.
- 🎯 **Carpet & Masa Protocol (v2 & v3)**: Native protocol integration guarantees flawless orientation for directional blocks (stairs, pistons, observers, hoppers) without camera snapping.
- 🔭 **Extended 64-Block Reach**: Fully configurable reach distance from 1.0 up to 64.0 blocks with spherical distance candidate early pruning.
- 🎒 **Inventory Buffer Caching**: Instant hotbar swapping directly from main inventory and shulker box container inspection.
- 🧹 **Clean & Unobtrusive**: Zero screen-clutter HUD boxes — all toggle and speed feedback is cleanly displayed in the vanilla actionbar above the hotbar.
- ⚙️ **MaLiLib & Mod Menu Integration**: Configure all options in-game via `M + C` or Mod Menu.

---

## ⌨️ Default Keybindings

| Keybinding | Default Key | Action |
| :--- | :---: | :--- |
| **Toggle Printer** | `V` | Toggles automatic schematic block placement on or off. |
| **Cycle Placement Speed** | `B` | Cycles burst throughput through `1` ➔ `3` ➔ `5` ➔ `10` blocks/tick. |
| **Open Config GUI** | `M + C` | Opens the MaLiLib in-game configuration menu. |

*(All keybindings can be customized in Options ➔ Controls ➔ Key Binds under the `Litematica Printer Pro` category).*

---

## 📦 Requirements

- **Minecraft**: `26.3` or `1.21.4`
- **Fabric Loader**: `>=0.16.0` (tested on `0.19.5+`)
- **Dependencies**:
  - [Fabric API](https://modrinth.com/mod/fabric-api)
  - [MaLiLib](https://modrinth.com/mod/malilib)
  - [Litematica](https://modrinth.com/mod/litematica)

---

## 🛠️ Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for Minecraft 26.3 or 1.21.4.
2. Download and place `fabric-api`, `malilib`, `litematica`, and `litematica-printer-pro-26.3-1.0.0.jar` into your `.minecraft/mods` folder.
3. Launch Minecraft, open a schematic in Litematica, and press `V` to print!
